Streamlining Answer Sheet Rectification, Grading, and Performance Analytics through Computer Vision
Project Description

OMR-Gradeline is a high-performance web application designed to automate and streamline exam evaluation using standard digital images of bubble sheets.

By leveraging robust, hardware-agnostic Computer Vision (OpenCV), the system instantly transforms raw camera uploads or scanned PDFs into rectified sheets and accurate grading metrics. It replaces expensive, specialized OMR scanners and custom heavy sheets with a flexible, high-speed software pipeline.

The application provides dual role-based portals for Admins (Graders) and Students, offering class-wide statistical charts, auto-key extraction, and dynamic PDF scorecard delivery.

Key Features
  • Quad-Corner Perspective Alignment: Auto-straightens and warps tilted or rotated sheets to 800x1100 px.
  • High-Precision Contour Filters: Filters bubble circles using aspect ratios and circularity (>0.78).
  • Double-Shade & Blank Indicators: Intelligently rejects multi-marked inputs and logs omitted questions.
  • Flexible Key Definition: Supports manual grids, bulk text synchronization, and auto-OMR sheet key extraction.
  • Dynamic PDF Report Cards: Builds formatted ReportLab PDFs containing visual color-annotated feedback.
  • High-Speed Batch Grading: Accepts multiple files or ZIP folders, auto-matching student records.

Modules & Sub-Modules
1. ADMINISTRATOR CONSOLE Mod 1
  • Subject/Exam Configurator: Setup classes and exams.
  • Answer Key Management: Grid sync or text synchronization.
  • Single OMR Grader: Instant camera grading tool.
  • ZIP Batch Processor: Auto-evaluates student folders.
  • Class Analytics Room: Average, passing, and score counts.
2. SECURE STUDENT DESK Mod 2
  • Verified Student Login: Secure session encryption.
  • Performance Log: Track average and exam score lists.
  • Evaluated Sheet Overlay: Color-annotated OMR view.
  • Official PDF Generator: Download compiled ReportLab PDFs.
3. COMPUTER VISION SYSTEM Mod 3
  • Geometric Rectifier: Detects 4-corner squares & warps image.
  • Circle Shape Filter: Isolates bubble circles by circularity metric.
  • Active Mask Density: Integrates pixels within contour space.
  • Feedback Painter: Overlays color circles over answer sheet.
